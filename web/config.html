More info — how Camera Switch works & camera testing status
How it works: Camera Switch uses one 3-position AUX channel. LOW is below 1300 µs, MIDDLE is 1300–1700 µs and HIGH is above 1700 µs. Each position stores a camera-specific selection ID. A value of 0 means unassigned.

OSD notification: After CamBuddy accepts a Camera Switch change it temporarily shows only the selection name, for example POV or Custom, in the selected OSD Display in destination for about 2.5 seconds, then automatically restores the normal OSD template. Critical camera warnings keep priority. If a selection ID was entered manually and has no saved name, the OSD safely falls back to LOW/MID/HIGH.

Discovery: While a supported camera is connected, use Discover Camera Options above to ask the camera for the presets or modes CamBuddy can currently use. Assign the returned entries to LOW, MIDDLE and HIGH, then save/apply the settings. The Wi-Fi AP configurator cannot perform live discovery because camera BLE is deliberately stopped while AP mode is active, but it can view, edit and save the same persistent profile IDs.

GoPro: Native saved preset discovery, named preset selection, LOW/MIDDLE/HIGH AUX switching and persistence have been tested on real hardware and are working. GoPro is currently the fully hardware-confirmed implementation.

DJI Action 4 / 5 Pro / 6: V1.0.2 currently exposes the verified basic shooting modes (Video, Slow Motion, Timelapse, Hyperlapse and Photo) through the same Camera Switch. Genuine DJI saved Custom Modes 1–5 have been identified in camera status, but their safe recall command is still under investigation, so native Custom Mode switching is not yet implemented or hardware-confirmed.

Osmo Nano: Native BLE DUML pairing, ARM-triggered recording and core telemetry are hardware-confirmed. Camera Switch now exposes the hardware-captured Nano shooting modes Video, Slow Motion, Timelapse, Hyperlapse, Photo, Panorama and SuperNight through native DUML 0x02/0xE1. The implementation is ready for real Nano hardware validation; it is not yet claimed hardware-confirmed.

Other cameras: Insta360 Camera Switch selections are not currently implemented. Profile IDs are camera/model-specific and should not be copied between different cameras unless explicitly supported.
