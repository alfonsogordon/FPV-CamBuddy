FPV CamBuddy at a glance

  • Betaflight 4.5 OSD support — physically tested via Pilot/Craft Name
  • Camera profile switching — 3-position AUX with native GoPro saved presets
  • Automatic ARM recording + configurable delayed stop on DISARM
  • Live camera OSD — ERR / RDY / REC, battery, time, mode and storage where available
  • Profile-name OSD — brief name-only message when profiles change
  • Browser Easy Config + field AP config with persistent settings
  • Supported camera backends: GoPro, DJI Action, Insta360, Sony, Blackmagic and Caddx
  • Hardware-confirmed cameras: GoPro HERO11 Black Mini, GoPro MAX2 and DJI Osmo Nano core workflow

Features

The useful bits, without the setup-guide wall of text.

📷 Multi-camera support

Camera backends for GoPro, DJI Action, Sony, Blackmagic, Insta360 and Caddx, with a clear tested-status table below so you can see what has actually been confirmed on hardware.

⏺ Automatic recording

Arm starts recording. Disarm restores the normal OSD immediately and stops the camera after a configurable delay — 5 seconds by default.

◱ Camera OSD

ERR / RDY / REC state plus battery, recording duration/time, mode, resolution, FPS, stabilisation and capacity where the camera reports them.

REC-only flight display

Messages containing camera Status can collapse to a clean REC-only display while armed + recording, with optional 1 Hz flashing.

⚠ Smart messages

First-arm CLEAN LENS reminder plus BATT LOW, REC LOW and CAM HOT warning support with defined display priority.

⌁ FPSteVe Easy Config

Read, change, save and verify the complete C3 configuration from the browser. Settings live on the C3 and survive power cycles.

▶ Integrated OSD Preview

Preview templates and simulate ARM, recording, hot/error states and first-arm behaviour before trying changes on the quad.

↻ Auto-connect + keepalive

Automatically discovers/reconnects to supported cameras. GoPro Wake Guard and keepalive provide the proven FPSteVe flight workflow.

⌁ Low-power BLE

Low Power is enabled by default at about −12 dBm, reducing unnecessary RF output beside your receiver and flight electronics.

⇄ AUX camera control

Optional Betaflight AUX camera-mode control plus LOW / MIDDLE / HIGH camera-profile switching. GoPro native saved presets are hardware-confirmed; profile changes can briefly show the profile name in the OSD.

🎬 Profile OSD + Demo

Optional name-only profile notification for about 2.5 seconds, with an on/off setting in USB and field AP configuration. Demo Mode includes CINEMATIC, ACTION and SLOW MOTION example profiles for testing without a camera.

Older Betaflight? Yes.

Betaflight 4.5 is fully hardware-confirmed using the Pilot/Craft Name compatibility path. BF 4.4 uses the same legacy path and is supported in the configurator, but still needs real-hardware confirmation.

Browser flashing

Install release firmware directly from the web flasher, then power-cycle once and continue straight to Easy Config.

📱 Field configurator

When the FPVCamBuddy Wi-Fi AP is active, open cambuddy.local on your phone. If .local is not resolved by the device/browser, 192.168.4.1 remains the fixed fallback.

Camera matching

Use Any-camera discovery or select a known camera when you need predictable behaviour around multiple devices.

  • Templates, preview and firmware logic validated
  • Other camera families have not necessarily been physically tested by FPSteVe

Quick Start

Flash the board, power-cycle it, open Easy Config, then wire the C3 to a spare FC UART and enable MSP at 115200. Place Pilot Name / Craft Name in BF 4.5, or Custom Messages on the newer path.
