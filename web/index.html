What it does

⏺ Auto record on arm

Start recording when the FC arms and stop on disarm, with configurable behaviour.

◱ Live OSD telemetry

Camera state, battery, recording information and other telemetry can be pushed into Betaflight's OSD.

⌁ Browser flash & config

Flash release builds and manage settings from a browser using WebSerial.

✎ Remembers cameras

Previously paired cameras can be stored on-device for easier reconnection.

⇄ AUX control

Use Betaflight AUX channels for supported camera actions and modes.

⚑ Betaflight compatibility

Supports the project's OSD message paths, including BF 4.5 compatibility mode.
