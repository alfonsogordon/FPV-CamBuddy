Features

The useful bits, without the setup-guide wall of text.

⏺ Automatic recording

Arm starts recording. Disarm restores the normal OSD immediately and stops the camera after a configurable delay — 5 seconds by default.

◱ Camera OSD

ERR / RDY / REC state plus battery, recording duration/time, mode, resolution, FPS, stabilisation and capacity where the camera reports them.

REC-only flight display

Messages containing camera Status can collapse to a clean REC-only display while armed + recording, with optional 1 Hz flashing.

⚠ Smart messages

First-arm CLEAN LENS reminder plus BATT LOW, REC LOW and CAM HOT warning support with defined display priority.

⌁ FPSteVe Easy Config

Read, change, save and verify the complete C3 configuration from the browser. Settings live on the C3 and survive power cycles.

▶ Integrated OSD Preview

Preview templates and simulate ARM, recording, hot/error states and first-arm behaviour before trying changes on the quad.

↻ Auto-connect + keepalive

Automatically discovers/reconnects to an available GoPro. Wake Guard respects a sleeping camera; keepalive holds the connection during use.

⌁ Low-power BLE

Low Power is enabled by default at about −12 dBm, reducing unnecessary RF output beside your receiver and flight electronics.

⇄ AUX camera control

Optional Betaflight AUX camera-mode control, including the existing GoPro Burst Slo-Mo workflow where supported.

BF 4.5 + newer OSD

Pilot/Craft Name compatibility for BF 4.5 plus Custom Messages 1–4 support for the newer Betaflight path.

Browser flashing

Install release firmware directly from the web flasher, then power-cycle once and continue straight to Easy Config.

Camera matching

Use Any-camera discovery or select a known camera when you need predictable behaviour around multiple devices.

🤘 Hardware-confirmed for V1

  • ESP32-C3 Super Mini + GoPro BLE auto-connect/reconnect
  • Real Betaflight 4.5 MSP + Pilot/Craft OSD
  • ARM → record and ERR / RDY / REC state
  • REC-only + flashing REC
  • CLEAN LENS first-arm behaviour
  • Immediate OSD restore on disarm + 5-second delayed stop
  • Configurator read/save/verification + power-cycle persistence
  • GoPro keepalive and normal camera power-off after FreeCLinker is removed

Implemented / awaiting matching hardware

  • BF 2026.6+ Custom Messages 1–4: implemented and Preview/logic validated, but no matching FC was available for physical V1 testing.
  • Warning conditions: warning/priority logic is Preview/firmware validated; every individual warning has not been deliberately forced on the installed test camera.
  • Some telemetry fields depend on the capabilities/data reported by the camera model.

Quick setup

Flash in the browser → power-cycle the C3 → open FPSteVe Easy Config → wire GPIO4/TX to FC RX and GPIO5/RX to FC TX → enable MSP at 115200 on that UART in Betaflight → place the appropriate OSD element. No normal CLI setup required.
