How to send CLI diagnostics

  1. Connect the CamBuddy C3 to a computer by USB and open the RC1 Configurator.
  2. Connect to the C3 and open the CLI / serial log view.
  3. Power the GoPro and reproduce the failed startup or reconnect (including a battery change).
  4. When enough log output has appeared, press Disconnect in the configurator. This stops the scrolling so you can select and copy the text.
  5. Copy the complete log into a text file or Discord code block and send it to FPSteVe. Include the camera model, whether it connected, and what happened.
  6. Repeat the test with GPIO12 connected, if applicable, and label both logs GPIO12 disconnected and GPIO12 connected.

Disconnect the serial connection in the configurator, not the USB cable, before copying. Never connect or disconnect GPIO wiring while powered.
