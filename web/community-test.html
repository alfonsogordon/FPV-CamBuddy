Who should test?

GoPro testers are absolutely wanted, along with DJI Action / Osmo, Insta360, Sony, Blackmagic and Caddx users. Results from cameras that fail are useful too.

For GoPro, please test native saved-preset discovery plus LOW / MIDDLE / HIGH switching. DJI Action 4 / 5 Pro / 6 can test the currently exposed Video, Slow Motion, Timelapse, Hyperlapse and Photo modes. DJI native Custom Modes 1–5 are not currently claimed as supported.

Quick test

  • Camera discovers and connects.
    More info
    Power the camera normally and let CamBuddy find it. Report if discovery takes unusually long, finds the wrong camera, repeatedly disconnects, or needs manual intervention.
  • Settings read, save and survive a reboot.
    More info
    Read the current settings in Easy Config, change something obvious, save it, then power-cycle CamBuddy and read it again. The saved value should still be there.
  • ARM starts recording; DISARM stops it. Repeat 5 times.
    More info
    Remove props for this bench test. Confirm the camera actually starts recording on every ARM and stops after the configured DISARM delay. Report missed triggers, duplicate triggers or unexpected delays.
  • Camera reconnects after camera and CamBuddy power cycles.
    More info
    Try power-cycling the camera, then CamBuddy/the quad. It should recover without needing to reconfigure the camera. Tell me if only one of those reboot sequences causes trouble.
  • Check available telemetry: recording state, battery, mode, recording time and storage.
    More info
    Not every camera exposes every value. Please report each field as working, wrong, blank or unavailable rather than treating unsupported telemetry as a whole-test failure.

Profile / Mode Switch + OSD

The LOW / MIDDLE / HIGH Profile Switch isn't GoPro-only; CamBuddy uses the supported mechanism available for each camera.

  • GoPro: discover native saved presets, assign LOW / MIDDLE / HIGH and test all three.
    More info
    Use Discover Camera Profiles while the GoPro is connected. Choose three saved GoPro presets, save them, then move the configured AUX switch through all three positions and confirm the expected native preset loads.
  • Other supported cameras: test any profiles/modes CamBuddy exposes.
    More info
    Capabilities vary by camera. DJI Action 4 / 5 Pro / 6 currently exposes the verified basic shooting modes. Do not assume a profile ID from one camera/model is valid on another.
  • Confirm the camera itself changes to the expected profile/mode.
    More info
    Check the camera screen/settings, not just CamBuddy's OSD. We want to verify that the requested change actually reached the camera.
  • Enable Show profile name in OSD; check the correct name appears for about 2.5 seconds and normal OSD returns.
    More info
    The temporary message should contain only the selected profile name, then disappear automatically. If no saved name exists it may fall back to LOW / MID / HIGH. Camera warnings should keep priority.
  • Test the Display in destination.
    More info
    Choose the OSD destination in Easy Config and confirm the temporary profile message appears in that selected Betaflight OSD element rather than another one.
  • Turn Profile OSD OFF; switching should still work without the message.
    More info
    This setting controls only the temporary OSD notification. It should not disable the actual camera profile/mode switch.
  • Reboot and confirm assignments are retained.
    More info
    Power-cycle CamBuddy and check LOW / MIDDLE / HIGH assignments and profile names are still present and still switch correctly.

AP / Field Configurator

  • Enable/open the CamBuddy AP and connect your phone to FPVCamBuddy.
    More info
    The AP is an open local configuration network. If normal auto-start is disabled, use the BOOT-button force-AP method. Camera BLE is deliberately stopped while field AP configuration is active.
  • Open http://cambuddy.local and confirm the configurator loads.
    More info
    This friendly local hostname is new in the V1.0.2 candidate. Please report your phone model/browser if it does not resolve.
  • Also test http://192.168.4.1 as the fixed fallback.
    More info
    This is the fixed AP address and should remain usable even if your device does not support or resolve the .local hostname.
  • Check saved settings, change one setting and save it.
    More info
    The AP page edits the same persistent configuration as the main USB configurator. Pick an easy-to-recognise setting so you can verify it after reboot.
  • Reboot CamBuddy and confirm the change is retained.
    More info
    After saving, power-cycle CamBuddy, reopen the configurator and verify the changed value. If possible, also read it later through the USB configurator.

cambuddy.local is new in this candidate and needs real-device testing; 192.168.4.1 remains the fallback.
