Who should test?

GoPro testers are absolutely wanted, along with DJI Action / Osmo, Insta360, Sony, Blackmagic and Caddx users. Results from cameras that fail are useful too.

For GoPro, please test native saved-preset discovery plus LOW / MIDDLE / HIGH switching. DJI Action 4 / 5 Pro / 6 can test the currently exposed Video, Slow Motion, Timelapse, Hyperlapse and Photo modes. DJI native Custom Modes 1–5 are not currently claimed as supported.

Quick test

  • Camera discovers and connects.
    More info
    Where: Open Easy Config → Recording Control and select the correct Camera type. Connect the camera as you normally would, then let CamBuddy scan.
    What should happen: CamBuddy should find the camera, connect and stay connected without you repeatedly restarting either device. If Camera matching is set to a specific/last camera, it should reconnect to that camera rather than another nearby one.
    Report: how long connection took and whether it disconnected, found the wrong camera or needed manual intervention.
  • Settings read, save and survive a reboot.
    More info
    Where: Use the main Easy Config page. Connect CamBuddy, let the page read the board, then change an easy-to-recognise setting such as Stop recording on disarm or the disarm delay.
    What should happen: Save/apply the settings, power CamBuddy off and back on, reconnect to Easy Config and read the board again. Your changed value should still be selected.
    Report: anything that resets, changes by itself or does not match what you saved.
  • ARM starts recording; DISARM stops it. Repeat 5 times.
    More info
    Before testing: REMOVE THE PROPS.
    Where: In Easy Config → Recording Control, make sure automatic recording is configured and Stop recording on disarm is enabled if you want the stop test. The disarm delay controls how long CamBuddy waits before stopping.
    What should happen: ARM the quad → the camera should begin recording. DISARM → the normal OSD should return immediately and the camera should stop after the configured delay. Repeat 5 times.
    Report: any missed start/stop, double trigger or noticeably wrong delay.
  • Camera reconnects after camera and CamBuddy power cycles.
    More info
    How: With a previously working connection, first restart only the camera and wait for CamBuddy to reconnect. Then power-cycle CamBuddy/the quad and check again.
    What should happen: It should reconnect automatically using the saved camera settings; you should not have to set the camera up again.
    Report: which reboot caused trouble, whether it eventually recovered, and roughly how long it took.
  • Check available telemetry: recording state, battery, mode, recording time and storage.
    More info
    Where: Look at the camera information shown in Easy Config and, if configured, the camera information in the Betaflight OSD.
    What to check: recording state, battery %, camera mode, recording time and storage/remaining time where your camera provides them.
    What should happen: values should update to match the real camera. Not every camera supports every field, so a blank unsupported field is not automatically a failure.
    Report: each field as correct, wrong, blank or unavailable.

Profile / Mode Switch + OSD

The LOW / MIDDLE / HIGH Profile Switch isn't GoPro-only; CamBuddy uses the supported mechanism available for each camera.

  • GoPro: discover native saved presets, assign LOW / MIDDLE / HIGH and test all three.
    More info
    Where: Connect the GoPro, then open Easy Config → AUX Switches → Camera Profile Switch. Use Discover Camera Profiles to read the native presets already saved on your GoPro.
    Set up: choose a Profile AUX channel, then assign a different GoPro preset to LOW, MIDDLE and HIGH. Save the configuration.
    What should happen: LOW (<1300 µs), MIDDLE (1300–1700 µs) and HIGH (>1700 µs) should each load the preset you assigned. Check the GoPro itself to confirm.
    Tip: use three obviously different presets so changes are easy to spot.
  • Other supported cameras: test any profiles/modes CamBuddy exposes.
    More info
    Where: Look under Easy Config → AUX Switches. Camera Mode Switch is the 2-position mode control; Camera Profile Switch is the independent 3-position LOW/MIDDLE/HIGH control.
    What should happen: only options supported/exposed for your camera should be used. DJI Action 4 / 5 Pro / 6 currently exposes Video, Slow Motion, Timelapse, Hyperlapse and Photo rather than verified native saved Custom Modes.
    Important: do not copy numeric profile IDs between different camera models.
  • Confirm the camera itself changes to the expected profile/mode.
    More info
    How: Move the configured AUX switch, then look directly at the camera screen/menu or resulting recording mode/preset.
    What should happen: the real camera should change to exactly the mode/preset assigned to that switch position. The CamBuddy OSD message alone does not prove the camera accepted the command.
    Report: if the OSD changes but the camera does not.
  • Enable Show profile name in OSD; check the correct name appears for about 2.5 seconds and normal OSD returns.
    More info
    Where: Easy Config → AUX Switches → Camera Profile Switch → Show profile name in OSD.
    What should happen: when you change profile, only the profile/preset name should appear for about 2.5 seconds, then your normal camera OSD should return. A manually entered ID with no saved name may show LOW / MID / HIGH instead.
    Also check: an important camera warning should take priority over this temporary profile message.
  • Test the Display in destination.
    More info
    Where: directly below Show profile name in OSD, use the Display in dropdown.
    What it does: it chooses which Betaflight OSD message slot CamBuddy uses for the temporary profile name. On BF 2026.6+ these are Custom Messages; older supported Betaflight versions use the compatible Pilot/Craft Name path where applicable.
    What should happen: the profile name appears in the destination you selected, not a different one.
  • Turn Profile OSD OFF; switching should still work without the message.
    More info
    Where: Easy Config → AUX Switches → Camera Profile Switch → Show profile name in OSD.
    What it does: this switch controls only the 2.5-second OSD message.
    What should happen: turn it OFF and move LOW/MIDDLE/HIGH again. The camera should still change profile/mode normally, but no temporary profile name should appear.
  • Reboot and confirm assignments are retained.
    More info
    How: after saving your Profile Switch setup, completely power CamBuddy off and back on, reconnect with Easy Config and read the board.
    What should happen: the Profile AUX channel, LOW/MIDDLE/HIGH assignments, saved names, Profile OSD toggle and Display in choice should all still be there and switching should still work.

AP / Field Configurator

  • Enable/open the CamBuddy AP and connect your phone to FPVCamBuddy.
    More info
    Where: AP behaviour is configured under Easy Config → Recording Control → WiFi Config AP. Enable it if you want automatic field-config access. Holding the CamBuddy board's BOOT button can also force the AP for recovery/configuration.
    How: when the AP is active, open your phone's Wi-Fi settings and join FPVCamBuddy.
    Note: camera BLE is deliberately stopped while the field AP is active, so live camera discovery is not expected from the AP page.
  • Open http://cambuddy.local and confirm the configurator loads.
    More info
    Where: after joining the FPVCamBuddy Wi-Fi network, open your normal browser and type http://cambuddy.local into the address bar.
    What should happen: the onboard FPV CamBuddy configurator should load without needing to remember an IP address.
    If it fails: that may be a hostname-resolution issue rather than an AP failure. Please report your phone model/browser, then try the 192.168.4.1 fallback below.
  • Also test http://192.168.4.1 as the fixed fallback.
    More info
    Where: while still connected to FPVCamBuddy, browse to http://192.168.4.1.
    What should happen: the same onboard configurator should load. This is the fixed fallback and should work even if cambuddy.local does not resolve.
    Report: whether each address works independently.
  • Check saved settings, change one setting and save it.
    More info
    Where: in the onboard AP configurator after opening cambuddy.local or 192.168.4.1.
    How: first check that the page shows your existing saved settings. Change one obvious setting, such as Stop recording on disarm or a delay value, then press the page's save/apply button.
    What should happen: the save should complete without the page losing your configuration.
  • Reboot CamBuddy and confirm the change is retained.
    More info
    How: after the AP page says the setting is saved, power CamBuddy completely off and back on. Re-enter AP mode, reconnect to FPVCamBuddy and open the configurator again.
    What should happen: your changed setting should still be there. If convenient, connect to the main USB Easy Config afterward too — both configurators should report the same saved value.

cambuddy.local is new in this candidate and needs real-device testing; 192.168.4.1 remains the fallback.
